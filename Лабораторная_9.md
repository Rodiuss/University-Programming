# Задание 2

> Даны основания и высоты двух равнобедренных трапеций. Найти сумму их периметров и сумму их площадей. (Определить процедуру для расчета пе-риметра и площади равнобедренной трапеции по ее основаниям и высоте.)

```pascal
program TrapezoidProgramm;

type
  Trapesoid = Class
  private
    sideA: Real;
    sideB: Real;
    height: Real;
  public    
    constructor (sideA: Real; sideB: Real; height: Real);
    begin
      self.sideA := sideA;
      self.sideB := sideB;
      self.height := height;
    end;
    
    function getPerimetr: Real;
    begin
      getPerimetr := (self.sideA + self.sideB) + 2 *
        sqrt(sqr(self.height) + sqr((self.sideA - self.sideB) / 2));
    end;
    
    function getSquare: Real;
    begin
      getSquare := 0.5 * (self.sideA + self.sideB) * height;
    end;
  end;

var
  sideA,
  sideB,
  height: Real;

var
  trapOne,
  trapTwo: Trapesoid;

begin
  (sideA, sideB, height) :=
    ReadReal3('Введите основание1, основание2, высоту (трапеция1):');
  trapOne := new Trapesoid(sideA, sideB, height);
  
  (sideA, sideB, height) :=
    ReadReal3('Введите основание1, основание2, высоту (трапеция2):');
  trapTwo := new Trapesoid(sideA, sideB, height);
  
  writeln('Сумма периметров трапеций: ',
    trapOne.getPerimetr + trapTwo.getPerimetr);
    
  writeln('Сумма площадей трапеций: ',
    trapOne.getSquare + trapTwo.getSquare);
  
end.
```

# Задание 3

> В некоторых языках программирования (например, в Паскале) не предусмотрена операция возведения в степень. Написать рекурсивную функцию для расчета степени n вещественного числа a (n — натуральное число).

```pascal
program NumberDegree;

function getNumberDegree(num: Real; deg: Real): Real;
begin
  var tempNum := num;
  if deg > 2 then tempNum := getNumberDegree(num, deg - 1);
  getNumberDegree := tempNum * num;
end;

var
  number,
  degree: Real;

begin
  (number, degree) := ReadReal2('Введите число и степень:');
  
  writeln('Результат: ', getNumberDegree(number, degree));
end.
```

# Задание 4

> 4.	Написать рекурсивную функцию для вычисления значения так называемой функции Аккермана для неотрицательных чисел n и m. Функция Аккермана определяется следующим образом:

$$A(n, m) = 
\begin{cases} 
m + 1, & \text{если } n = 0, \\ 
A(n - 1,\ 1), & \text{если } n \neq 0, \ m = 0, \\ 
A(n - 1,\ A(n,\ m - 1)), & \text{если } n > 0, \ m > 0. 
\end{cases}$$

```pascal
program AckermannFunction;

function Ackermann(m, n: integer): int64;
begin
  if m = 0 then
    Result := n + 1
  else if (m > 0) and (n = 0) then
    Result := Ackermann(m - 1, 1)
  else if (m > 0) and (n > 0) then
    Result := Ackermann(m - 1, Ackermann(m, n - 1))
  else
    Result := -1;
end;

var
  m, n: Integer;
begin
  m := ReadInteger('Введите m:');
  n := ReadLnInteger('Введите n:');
  
  if (m < 0) or (n < 0) then
    WriteLn('Ошибка: m и n должны быть неотрицательными!')
  else
    WriteLn('A(', m, ', ', n, ') = ', Ackermann(m, n));
end.
```
