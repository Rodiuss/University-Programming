# Задание 1

> Составить процедуру, "рисующую" на экране горизонтальную линию из любого числа символов `*`.

```pascal
program MainLine;

procedure writeLine(number: Integer);
begin
  if (number >= 1) then writeLine(number-1);
  writeln('*' * number);
end;

begin
  writeLine(ReadInteger('Введите любое число: '));
end.
```
