# Задание 2

> Напишите программу поиска двузначных чисел, удовлетворяющих следующему условию: если к сумме цифр такого числа прибавить квадрат этой суммы, то получится само это число.

```pascal
program FunnyNumbers;

const cycleStartNumber = 10;
const cycleEndNumber = 99;

var digitSum: Integer := 0;

begin
  for var i := cycleStartNumber to cycleEndNumber do
  begin
    digitSum := (i mod 10) + (i div 10);
    if (i = digitSum + sqr(digitSum)) then writeln(i);
  end;
end.
```

# Задание 3

> В городе, чье население с каждым годом растет на 10%, живет 9 870 человек. Напишите программу, которая отображает ежегодную численность населения на 10 лет вперед.

```pascal
program Population;

const divProcent = 0.10;

var currentPopulation: Integer := 9870;

begin
  for var i := 1 to 10 do
  begin
    currentPopulation += round(currentPopulation * divProcent);
  end;

  writeln('Численность населения на 10 лет вперёд: ', currentPopulation);
end.
```


# Задание 5

> Дано натуральное четырехзначное число n (n ≤ 9999). Определить, является ли оно палиндромом («перевертышем»), с учетом всех четырех цифр. Например, палиндромами являются числа: 2222, 6116, 7447.

```pascal
program Palindrom;

const endCycleNumber = 3;

var num: Integer;

function getDigitByIndex(number, index: integer): integer;
begin
  case index of
    0: getDigitByIndex := (number div 1000);
    1: getDigitByIndex := ((number div 100) mod 10);
    2: getDigitByIndex := ((number div 10) mod 10);
    3: getDigitByIndex := (number mod 10);
  end;
end;

begin
  num := readInteger('Введите натуральное четырёхзначное число:');
  
  for var i := 0 to endCycleNumber do
  begin
    if (getDigitByIndex(num, i)
      <> getDigitByIndex(num, endCycleNumber - i)) then
        begin
          writeln('Число не является палиндромом');
          exit;
        end;
  end;
  
  writeln('Число является палиндромом');
end.

```
