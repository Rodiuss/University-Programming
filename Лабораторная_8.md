# Задание 1

> Вычислить и вывести с 7 знаками после запятой значение х, найденное по формуле:
> 
> $x = \frac{\sqrt{6} + 6}{2} + \frac{\sqrt{13} + 13}{2} + \frac{\sqrt{21} + 21}{2}$

```pascal
program CalculateX;
var
  x: real;

function Calculate: real;
begin
  Calculate := (sqrt(6) + 6) / 2 + 
               (sqrt(13) + 13) / 2 + 
               (sqrt(21) + 21) / 2;
end;

begin
  x := Calculate;
  writeln('x = ', x:0:7);
end.
```

# Задание 2

> Найти периметр фигуры ABCD по заданным сторонам AB, AD и DC. (Определить функцию для расчета гипотенузы прямоугольного треугольника по его катетам.)

```pascal
program FigurePerimeter;
var
  AB, AD, DC, perimeter: real;

function Hypotenuse(a, b: real): real;
begin
  Hypotenuse := sqrt(a * a + b * b);
end;

begin
  write('Введите стороны AB, AD, DC: ');
  readln(AB, AD, DC);
  
  perimeter := AB + AD + DC + Hypotenuse(AB - DC, AD);
  writeln('Периметр фигуры ABCD: ', perimeter:0:4);
end.
```

# Задание 3

> Даны три квадратных уравнения: $ax² + bx + c, bx² + ax + c, cx² + ax + b$. Сколько из них имеют вещественные корни? (Определить функцию, позволяющую распознавать наличие вещественных корней в квадратном уравнении.)

```pascal
program QuadraticEquations;
var
  a, b, c, count: integer;

function HasRealRoots(k, m, n: real): boolean;
var
  discriminant: real;
begin
  discriminant := m * m - 4 * k * n;
  HasRealRoots := discriminant >= 0;
end;

begin
  write('Введите коэффициенты a, b, c: ');
  readln(a, b, c);
  
  count := 0;
  if HasRealRoots(a, b, c) then count := count + 1;
  if HasRealRoots(b, a, c) then count := count + 1;
  if HasRealRoots(c, a, b) then count := count + 1;
  
  writeln('Количество уравнений с вещественными корнями: ', count);
end.
```

# Задание 4

> Два простых числа называются "близнецами", если они отличаются друг от друга на 2 (таковы, например, числа 41 и 43). Напечатать все пары чисел - "близнецов", не превышающих число 200. (Определить функцию, позволяющую распознавать простые числа.)

```pascal
program TwinPrimes;
var
  i: integer;

function IsPrime(num: integer): boolean;
var
  j: integer;
begin
  if num < 2 then
    IsPrime := false
  else
  begin
    IsPrime := true;
    for j := 2 to trunc(sqrt(num)) do
      if num mod j = 0 then
      begin
        IsPrime := false;
        break;
      end;
  end;
end;

begin
  writeln('Пары простых чисел-близнецов до 200:');
  for i := 2 to 198 do
    if IsPrime(i) and IsPrime(i + 2) then
      writeln(i, ' и ', i + 2);
end.
```

# Задание 5

> Получить все шестизначные счастливые номера. Счастливым называют такое шестизначное число, в котором сумма его первых трех цифр равна сумме его последних трех цифр. (Определить функцию для расчета суммы цифр трехзначного числа.)

```pascal
program LuckyNumbers;
var
  i: integer;

function SumOfDigits(num: integer): integer;
var
  sum: integer;
begin
  sum := 0;
  while num > 0 do
  begin
    sum := sum + (num mod 10);
    num := num div 10;
  end;
  SumOfDigits := sum;
end;

begin
  writeln('Шестизначные счастливые номера:');
  for i := 100000 to 999999 do
    if SumOfDigits(i div 1000) = SumOfDigits(i mod 1000) then
      write(i, ' ');
  writeln;
end.
```
