# Задание 1

> Дан массив целых чисел (элементы массива вводятся с клавиатуры). Найти сумму элементов, имеющих нечётные значения и сумму элементов, имеющих чётные индексы.

```pascal
program ArraySum;

var arrayOfDigit: array of Integer;
var
  arrayLenght,
  evenSum,
  oddSum: Integer;

begin
  arrayLenght := ReadInteger('Введите размер массива:');
  arrayOfDigit := ReadArrInteger('Введите числа:', arrayLenght);
  
  for var i := 0 to Length(arrayOfDigit) - 1 do
  begin
    evenSum += i mod 2 = 0 ? arrayOfDigit[i] : 0;
    oddSum += arrayOfDigit[i] mod 2 <> 0 ? arrayOfDigit[i] : 0;
  end;
  
  writeln('Сумма элементов, имеющих нечетное значение: ', oddSum);
  writeln('Сумма элементов, имеющих черный индекс: ', evenSum);
end.
```

# Задание 2

> Дан массив вещественных чисел (элементы массива генерируются случайным образом в диапазоне от -17 до 17). Определить количество пар соседних элементов с разными знаками.

```pascal
program ArrayPars;

var 
  arrayLenght,
  count: Integer;
var arrayOfReal: array of Real;

begin
  arrayLenght := ReadInteger('Введите размер массива:');
  arrayOfReal := ReadArrReal('Введите числа', arrayLenght);
  
  for var i := 0 to Length(arrayOfReal) - 2 do
  begin
    if ((arrayOfReal[i] > 0) and (arrayOfReal[i + 1] < 0)) or
      ((arrayOfReal[i] < 0.0) and (arrayOfReal[i + 1] > 0)) then count += 1;
  end;
  
  writeln('Количество пар соседних элементов с разными знаками: ', count);
end.
```

# Задание 4

> Вставить в массив два заданных числа: первое после любого из максимальных элементов, второе — перед ним.

```pascal
program MaxNumbersGame;

const arrLenght: Integer = 10;
var arrOfNum: array of Integer;
var maxInd: Integer;

function findMax<T>(arr: array of T; stArr: Integer; endArr: Integer):
  (T, Integer);
where T: IComparable<T>;
var arrMid: Integer;
var frstMax, scndMax: (T, Integer);
begin
  if (stArr = endArr) then
  begin
    Result := (arr[endArr], endArr);
    exit;
  end;
  
  arrMid := (stArr + endArr) div 2;
  frstMax := findMax(arr, stArr, arrMid);
  scndMax := findMax(arr, arrMid + 1, endArr);
  
  Result := frstMax[0].CompareTo(scndMax[0]) > 0 ? frstMax : scndMax;
end;

begin
  arrOfNum := ArrRandomInteger(arrLenght, 1, 15);
  maxInd := findMax(arrOfNum, 0, arrOfNum.Length - 1)[1];
  
  println(String.Format('MAX(arrOfNum) := {0} [{1}]',
    arrOfNum[maxInd],
    maxInd));
    
  if maxInd = 0 then
    arrOfNum.Append(arrOfNum[maxInd + 1]).ToArray.Println
  else if maxInd = arrLenght - 1 then
    arrOfNum.Append(arrOfNum[maxInd - 1]).ToArray.Println
  else
    arrOfNum.Concat([arrOfNum[maxInd - 1], arrOfNum[maxInd + 1]])
      .ToArray.Println;
end.
```

# Задание 5

> В массиве из 20 элементов числа образуют неубывающую последовательность. Несколько элементов, идущих подряд, равны между собой. Найти количество таких элементов. Сколько различных чисел имеется в массиве?

```pascal
program SimilarEl;

const myArrLnght: Integer = 20;
var myArr: array of Integer;

function similarCount<T>(arr: array of T): Integer;
var count: Integer;
begin
  for var i := 0 to arr.Length - 2 do
  begin
    if arr[i] = arr[i+1] then count += 1;
  end;
  Result := count;
end;

begin
  myArr := ArrRandomInteger(myArrLnght, 0, 15);
  
  myArr.println;
  String
    .format('{0} - кол-во эл-ов идущих подряд', similarCount(myArr)).println;
  
  String
    .format('{0} - кол-во различных эл-ов', myArr.Distinct.Count).println;
end.
```
