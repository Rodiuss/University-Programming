# Задание 1

> Дано действительное число a. Для функций, графики которых представлены на рисунках, вычислить $f(a)$.
>
> ![lab_3_1a](/img/lab_3_1a.png)
> ![lab_3_1b](/img/lab_3_1b.png)

```pascal
program PiecewiseFunctions;
var
  a, result: real;
begin
  write('Введите действительное число a: ');
  readln(a);
  
  // Для графика а): V-образная функция
  if a <= -1 then
    result := -1
  else if (a > -1) and (a <= 1) then
    result := a
  else
    result := 1;
  
  writeln('f(a) для графика а) = ', result:0:4);
  
  // Для графика б): функция с разрывом
  if a < 0 then
    result := a * a
  else if a = 0 then
    result := 1
  else
    result := sqrt(a);
  
  writeln('f(a) для графика б) = ', result:0:4);
end.
```

# Задание 2

> Даны три целых числа (числа должны быть различные). Напишите программу, определяющую среднее из этих чисел. Средним назовем число, которое больше наименьшего из данных чисел, но меньше наибольшего. В программе предусмотрите проверку корректности ввода чисел (если будут введены одинаковые, вывести сообщение о некорректном вводе данных).

```pascal
program MiddleNumber;
var
  a, b, c, middle: integer;
begin
  write('Введите три различных целых числа: ');
  readln(a, b, c);
  
  // Проверка на различные числа
  if (a = b) or (a = c) or (b = c) then
  begin
    writeln('Ошибка: числа должны быть различными!');
    exit;
  end;
  
  // Поиск среднего числа
  if ((a > b) and (a < c)) or ((a < b) and (a > c)) then
    middle := a
  else if ((b > a) and (b < c)) or ((b < a) and (b > c)) then
    middle := b
  else
    middle := c;
  
  writeln('Среднее число: ', middle);
end.
```

# Задание 3

> Напишите программу поиска количества отрицательных чисел среди четырех целых чисел $A, B, C$ и $D$.

```pascal
program NegativeCount;
var
  A, B, C, D, count: integer;
begin
  write('Введите четыре целых числа A, B, C, D: ');
  readln(A, B, C, D);
  
  count := 0;
  
  if A < 0 then count := count + 1;
  if B < 0 then count := count + 1;
  if C < 0 then count := count + 1;
  if D < 0 then count := count + 1;
  
  writeln('Количество отрицательных чисел: ', count);
end.
```

# Задание 5

> Даны действительные положительные числа $a,b,c,x,y$. Составить программу, которая проверяет, пройдет ли кирпич с ребрами $a,b,c$ в прямоугольное отверстие со сторонами x и y. Просовывать кирпич в отверстие разрешается только так, чтобы каждое из его ребер было параллельно или перпендикулярно каждой из сторон отверстия.

```pascal
program BrickInHole;
var
  a, b, c, x, y: real;
  fits: boolean;
begin
  write('Введите размеры кирпича (a, b, c): ');
  readln(a, b, c);
  write('Введите размеры отверстия (x, y): ');
  readln(x, y);
  
  // Проверка положительности чисел
  if (a <= 0) or (b <= 0) or (c <= 0) or (x <= 0) or (y <= 0) then
  begin
    writeln('Ошибка: все числа должны быть положительными!');
    exit;
  end;
  
  // Кирпич проходит, если две его наименьшие стороны меньше или равны
  // сторонам отверстия (возможны 6 вариантов ориентации)
  fits := ((a <= x) and (b <= y)) or  // ориентация 1
          ((a <= x) and (c <= y)) or  // ориентация 2
          ((b <= x) and (c <= y)) or  // ориентация 3
          ((a <= y) and (b <= x)) or  // ориентация 4 (повернуто)
          ((a <= y) and (c <= x)) or  // ориентация 5 (повернуто)
          ((b <= y) and (c <= x));    // ориентация 6 (повернуто)
  
  if fits then
    writeln('Кирпич проходит в отверстие')
  else
    writeln('Кирпич НЕ проходит в отверстие');
end.
```
